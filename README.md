# F1 Insider

F1 Insider 是以繁體中文為主的 Formula 1 入門知識網站，採用 HTML5、CSS3 與 Vanilla JavaScript，適合部署至 GitHub Pages。

## 專案結構

```text
f1-insider/
├── AGENTS.md
├── README.md
├── index.html
├── pages/
│   ├── drivers.html
│   ├── teams.html
│   ├── circuits.html
│   └── racing-guide.html
├── css/
│   └── style.css
├── js/
│   └── main.js
└── assets/
    ├── images/
    └── icons/
```

## 本次首頁內容

- Navigation Bar：桌面版導覽列與手機版漢堡選單
- Hero Section：F1 Insider 品牌介紹與賽車視覺
- Featured Content：賽事指南、車手、賽道三張主題卡片
- Category Entry：Drivers、Teams、Circuits、Racing Guide 四大分類入口
- Footer：網站簡介與回到頁首連結

## 本機預覽

直接以瀏覽器開啟 `index.html`，或使用 VS Code 的 Live Server 擴充功能預覽。

## GitHub Pages

將整個 `f1-insider` 資料夾內容推送至 GitHub repository，並在 Repository Settings → Pages 選擇部署分支與根目錄即可。

> 分類頁目前為導覽目的的簡易佔位頁，後續可依 AGENTS.md 規範補上完整內容。
